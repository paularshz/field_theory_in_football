## Vector field theory in motion: Revealing latent potentials in football dynamics
This repository contains the MATLAB source code associated with the manuscript "Vector field theory in motion: Revealing latent potentials in soccer dynamics".

The code provides a computational framework to model the collective movement of football players as a vector field, allowing for the reconstruction of a scalar potential field that drives the dynamics of the match.

The included scripts facilitate the transformation of discrete player trajectories into a field representation to analyze space creation and occupation, a process that requires user-provided spatially binned average velocity matrices (Wx,Wy) as input. Within the main script, users will find the complete workflow to visualize the vector field, compute the rotational component, verify flow continuity via Gauss's theorem, and numerically solve for and visualize the resulting scalar potential surface.
